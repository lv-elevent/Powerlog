# Personal Daily OS — UI 视觉规范与页面详细设计 V1.0

> 日期：2026-08-17  
> 产品：Personal Daily OS  
> 平台：Mobile First PWA / Responsive Web  
> 设计目标：明亮、轻量、私人、长期使用、高信息密度但不压迫

---

# 1. 设计目标

Personal Daily OS 的 UI 不应该像传统企业后台，也不应该像复杂健身 App。

整个产品视觉要让用户产生一种感觉：

> **“今天发生的事情都在这里，很清楚，但不会逼我填很多东西。”**

核心设计目标：

1. **手机端优先**
2. **高频操作 1～3 次点击完成**
3. **Today 页面承担绝大多数日常操作**
4. **信息密度高，但保持呼吸感**
5. **数字、进度、历史趋势优先可读**
6. **卡片化但不过度卡片化**
7. **不使用黑暗、赛博、强渐变风格**
8. **未来 AI 功能加入后仍然保持统一视觉**

# 5. 页面背景

全局：

```css
background: #F8FAFC;
```

卡片：

```css
background: #FFFFFF;
border: 1px solid #E2E8F0;
```

避免：

- 整页纯白导致层级消失
- 大面积渐变
- 深色背景
- 彩色大卡片堆叠

# 6. 圆角系统

统一使用偏大的圆角。

```text
XS    8px
SM   12px
MD   16px
LG   20px
XL   24px
2XL  28px
```

使用建议：

| 组件 | 圆角 |
|---|---|
| Input | 14px |
| Button | 14～16px |
| Small Card | 16px |
| Main Card | 20px |
| Bottom Sheet | 24px 顶部 |
| Modal | 24px |
| Quick Action | 16px |

不要所有东西都用 32px。

---

# 7. 阴影

整体阴影必须克制。

默认 Card：

```css
box-shadow:
0 1px 2px rgba(15,23,42,.04),
0 4px 14px rgba(15,23,42,.04);
```

浮层：

```css
box-shadow:
0 12px 40px rgba(15,23,42,.14);
```

原则：

> 边框负责结构，阴影只负责轻微浮层感。

```css

-apple-system,
BlinkMacSystemFont,
"PingFang SC",
"Microsoft YaHei",

Arial,

```

```text

```

这样体重、热量、金额、训练重量不会跳动。

# 72. Motion 规范

```text

```

# 76. 页面组件复用原则

不要复制页面 UI。

例如：

```text
Today Timeline
History Timeline
```

应该共用：

```text
DailyTimeline
```

区别只在：

```text
mode="today"
mode="history"
```

同理：

```text
MealSummary
WorkoutSummary
NutritionProgress
```

都必须复用。

# 77. 数据与 UI 分层

组件禁止直接：

```text
supabase.from(...)
```

正确：

```text
UI Component
  ↓
Feature Hook / Action
  ↓
API Client
  ↓
Next.js API
```

这样后续换数据源不需要重写 UI。
